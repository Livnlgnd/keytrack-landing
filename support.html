How can we help?

Setup guides, demo access, and contact information for KeyAudit Pro.

Try the demo

Open the mobile app and select Try demo workspace on the sign-in screen. The demo loads a sample apartment property, units, checkouts, and audit history without a desktop, account, or network.

App Review: use the demo action first. Normal standalone setup is also available from the same screen.

Pair a phone

On the Windows desktop, open Settings → Multi-Terminal Sync, enable network terminals, and scan the QR code from the phone. Both devices must be on the same local network.

License and subscriptions

Buy or expand a desktop license from the website. After checkout, open the license page with your order ID and email. For Cloud Backup or LAN Sync, paste your current license key so the add-on is merged into the upgraded key.

The iOS app does not sell subscriptions or link to external checkout pages.

Backups and data

Export a JSON backup from Settings → Local data & backups before clearing app data or moving devices. Import replaces all local data on that device.

Contact support

Include your company name, license type, platform (Windows/iOS/Android), and a short description of the issue. For order issues, include the Lemon Squeezy order ID.
